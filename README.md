# FOMOチェッカー

高校生が、自分のFOMO（見逃すことへの不安）傾向やスマートフォン・SNSとの関わり方を**振り返る**ためのWebアプリです。
研究全体のメッセージは「画面よりも、目の前の『今』を。」。啓発ポスターで「気づき」を促し、このアプリで自分の利用を「振り返る」役割を担います。

> このアプリは**医療・心理診断ツールではありません**。スマホやSNSをやめさせるものでも、否定するものでもありません。

## 動かし方

- GitHub Pages：リポジトリの Settings → Pages で公開します。
- 手元で確認：`index.html` をブラウザで開くだけで動きます（ビルド不要、フレームワーク不使用）。
- グラフはChart.js（CDN）を使います。読み込めない場合は表だけが表示されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 読み込み順の定義 |
| `style.css` | 見た目（ダークモード対応） |
| `questions.js` | 質問データ、尺度定義、研究結果の数値（β・R²・F・p）、レーダーチャートの比較用平均 |
| `research.js` | 「この研究について」に表示する文章 |
| `scoring.js` | 採点（平均点、文面用の段階、相対的に高い因子の判定） |
| `feedback.js` | ルールベースのフィードバック文の生成 |
| `storage.js` | 履歴の保存（クッキー／ローカルストレージ） |
| `app.js` | 画面表示とイベント処理 |

## よく変える場所

- **質問の追加・変更**：`questions.js` の `QUESTIONS`（尺度ごとの配列）。問数の表示は自動で変わります。
- **研究結果の数値**：`questions.js` の `RESEARCH`。フィードバック文中のβ値もここから入ります。
- **レーダーチャートの平均**：`questions.js` の `RESEARCH.sample`。
  現在の値は、t検定の表（女性n=113、男性n=90）の平均点を人数で加重平均した全体平均です。
  全体の平均が分かる場合は差し替えてください。
- **フィードバック文**：`feedback.js` の各テンプレート。
- **研究の説明文**：`research.js`。

## 判定のルール

- 文面の切り替えに使う段階は、1〜5点を3等分した**目安**（`scoring.js` の `LEVEL_THRESHOLDS`）です。正式なカットオフ値ではないため、画面上も「他の人との比較や基準ではない」と明記しています。
- F1〜F3のうち相対的に高い因子は、本人の平均点どうしを比べて判定します（差が0.5未満なら「差なし」、同点なら複数表示）。
- **性別・学年・所属によって、結果の見せ方やアドバイスを変えません。**
- 「関連」と「因果」を区別し、「依存」「危険」「改善」「悪化」などの判定語は使いません。

## 保存とプライバシー

- 名前・学校名・メールアドレス・電話番号・SNSアカウントは集めません。
- 保存するのは、日時とFOMO・F1・F2・F3の得点だけです。
- 初期の保存方法は**クッキー**です（使えない環境では自動でローカルストレージになります）。右上の⚙から切り替えられ、履歴も引き継がれます。
  クッキーはサイトを開くたびに送信される仕組みのため、画面の説明にもその旨を書いています。

## 生成AIを接続する場合（任意）

**APIキーをブラウザ側のJavaScriptに書いてはいけません。** 必ずサーバー側から呼び出します。

```
ブラウザ(app.js) ──POST 得点と段階のみ──▶ 自前のサーバー ──APIキーを使って──▶ 生成AI API
                ◀── { "advice": "..." } ──                ◀──────────────────
```

1. サーバー（Cloudflare Workers、Vercel Functions、Node.jsなど）を用意し、APIキーは**環境変数**に置きます。
2. サーバーは次の入力だけを受け取ります。
   `{ "scores": {fomo,f1,f2,f3}, "levels": {...}, "topFactors": [...] }`
   数値の範囲と型を検証し、自由記述は受け取りません。
3. 生成AIへの指示には、次を必ず含めます。
   - 診断・断定をしない（「FOMOである」「依存である」などと言わない）
   - 性別などで内容を変えない
   - SNSやスマホを否定しない
   - 「関連」と「因果」を混同しない
   - 振り返りの問いや具体的な工夫を、短い文章で提案する
4. 返す形は `{ "advice": "文章" }`。`app.js` は800文字までに切り詰めて、`textContent` で表示します。
5. 悪用を防ぐため、サーバー側で呼び出し回数の制限と、許可するオリジン（CORS）の設定を行います。
6. `app.js` の `AI_CONFIG.endpoint` にサーバーのURLを入れると、「AIで振り返りのヒントを作る」ボタンが表示されます。
   空のままなら、ルールベースのフィードバックだけで動きます（AIの有無で判定ロジックは変わりません）。

## 公開前のチェック

- 研究結果の数値と文章が、ポスターおよび論文・発表資料と一致しているか。
- Chart.jsを外部CDNから読み込んでいます。外部通信を避けたい場合は、ファイルをリポジトリに置いて読み込み先を変えてください（CDNのままにする場合は、`integrity`属性の追加を検討してください）。
